# Tài liệu repository

## Planning Engine

1. [`PLANNING_PROCESS.md`](PLANNING_PROCESS.md) — quy trình vận hành end-to-end, dùng để chạy/kiểm tra/xử lý lỗi.
2. [`PLANNING_ENGINE.md`](PLANNING_ENGINE.md) — kiến trúc kỹ thuật và boundary module.
3. [`VBA_MIGRATION_MAP.md`](VBA_MIGRATION_MAP.md) — mapping workbook/VBA cũ sang Python.
4. [`../src/planning/README.md`](../src/planning/README.md) — quy tắc sắp xếp source code planning.

## MobiWork / SharePoint pipeline

- [`ARCHITECTURE.md`](ARCHITECTURE.md) — kiến trúc ETL MobiWork -> SharePoint.
- [`OPERATIONS.md`](OPERATIONS.md) — vận hành production sync.

## Quy tắc đọc tài liệu

- Muốn biết **hệ thống chạy thế nào**: đọc `PLANNING_PROCESS.md`.
- Muốn biết **sửa code ở file nào**: đọc `src/planning/README.md`.
- Muốn biết **VBA cũ đã chuyển sang đâu**: đọc `VBA_MIGRATION_MAP.md`.
- Muốn biết **SharePoint/MobiWork sync hoạt động thế nào**: đọc `ARCHITECTURE.md` + `OPERATIONS.md`.
